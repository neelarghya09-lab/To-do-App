# 📋 To-Do App

A sleek and simple **To‑Do web application** built with **HTML, CSS, and JavaScript**.  
This app allows users to add, edit, delete, and mark tasks as complete, with a clean mobile‑style interface. Tasks are saved in **localStorage**, so they persist even after refreshing the page.

---

## 🚀 Features
- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 💾 Persistent storage using localStorage
- 📱 Mobile‑style responsive design
